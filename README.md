# Aplikasi_pemesanan_tiket_pesawat
Aplikasi pemesanan tiket pesawat sederhana berbasis console.

Fitur-fitur pada program
- Sistem Peran: Memisahkan akses antara penumpang biasa dan administrator sistem.
- Lihat & Cari Jadwal: Pengguna bisa melihat daftar penerbangan yang tersedia beserta rute dan harganya.
- Peta Kursi Interaktif dalam bentuk Matrix 2D: Menampilkan visualisasi denah kursi pesawat ($4 \times 4$). Kursi yang belum terisi bertanda [O], sedangkan yang sudah dipesan bertanda [X].
- Hitung Otomatis & Pajak: Menghitung total biaya pemesanan tiket secara otomatis termasuk komponen pajak PPN 11%.
- Cetak E-Ticket: Menampilkan tanda terima/struk transaksi penerbangan digital langsung di layar.
- Kelola Jadwal (Admin): Admin dapat menambahkan rute dan penerbangan baru ke dalam sistem saat program berjalan.
- Penyimpanan Data secara terbuka:
        - Menyimpan histori pemesanan ke file.
        - Memperbarui peta dan ketersediaan kursi ke file.
